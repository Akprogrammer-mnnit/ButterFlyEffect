# Butterfly Effect

🦋 A powerful developer productivity tool that analyzes the code dependency graph to find the "blast radius" of your changes.

## Features
* Analyzes function dependencies across your JavaScript/TypeScript project.
* Visually flags high-risk changes directly in your editor using CodeLens.
* Generates an AI-powered impact report before you commit.

## Requirements
Ensure your Butterfly Effect backend is running and the URL is configured in your VS Code settings.
